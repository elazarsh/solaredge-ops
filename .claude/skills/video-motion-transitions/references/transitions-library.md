## דוגמת תוכנית (`transition-plan-example.json`)
נבנתה לסרט 'נח' (60+ מעברים): כל זוג תמונות → `{kind, params}`. עקרונות בחירה:
- הצפה/מבול → `water` (up) ; התפוגגות → `water` (down) ; חורבן → `burn`/`shatter`/`smash` ; סגירת פרק → `dipblack`.
- דלת/אוהל/פתח → `portal` (`shape` rect/ellipse) ; כניסה לדמות → `fill`/`zoomthrough` ; קשר בין שני חפצים → `match`.
- קשת בענן ↔ קשת חץ: `match`; דמעה ↔ טיפת מים: `match`; כוס ↔ מגדל: `match`.
- רגש עדין (חום, זיכרון) → `goldbloom`/`defocus`/`colorseep`; מפנה לקור → `colordrain`/`ink`.
