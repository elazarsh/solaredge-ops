# Visual code catalog

Codes are plain-language art directions. The slash is a convention. Expand each into a full prompt.

## A. Viewpoint (how we look inside / through)
- `/xray` - see beneath the surface
- `/explodedview` - every component separated, with assembly order
- `/cutaway` - part removed to show the interior
- `/crosssection` - slice diagram
- `/anatomy` - labelled parts of a thing (e.g. a LinkedIn post)
- `/layers` - idea in stacked layers

## B. Rendering style
- `/handwritten` - notebook paper, arrows, circles, underlines, margin notes
- `/stickynotes` - colourful notes on a board
- `/blueprint` - blue engineering drawing
- `/sketch` - fast rough drawing
- `/lego` - brick-built, playful
- `/figurine` - collectible action figure
- `/miniature` - tiny world representing a big idea
- `/isometric` - angled top-down tiny 3D environment
- `/clayrender`, `/wireframerender`, `/lowpoly`, `/papercut`, `/claymation`, `/pixelart`, `/vectorflat`, `/watercolor`, `/oilpainting`, `/popart`, `/anime`

## C. Structure (information display)
`/infographic` `/timeline` `/mindmap` `/roadmap` `/flowchart` `/comparison` (also `/versus` `/beforeafter` `/thenvsnow`) `/dashboard` `/storyboard` `/network` `/ecosystem`
Modifiers: `/3D` `/map` `/evolution` `/funnel` `/workflow` `/framework` `/viral` `/authority` `/linkedin` `/carousel`

## E. Prompt skeleton

```
Create a [aspect ratio] [code stack] of [subject].
Structure: [timeline/mindmap/...] with [N] items.
Exact text (verbatim, Hebrew, RTL): "..." "..." "..."
Colors: [hex or brand code]. Style: [rendering]. Viewpoint: [xray/cutaway].
Keep: [shape/logo/colors of the attached source]. Do not add: [people/logos/extra text].
```
