# Hook bank (Hebrew)

The first 1.5–3 s decide delivery. A hook = **on-screen text + first VO line + first visual**,
all saying the same thing. Text must be readable in 0.5 s: ≤ 6 words, huge, high contrast.

Write 3 hooks per concept, each from a **different pattern**. Always adapt gender and
address (at/ata/atem) to the audience; for job ads see `legal-il.md`.

| Pattern | Template | Example |
|---|---|---|
| Direct question (identity) | "[תכונה]? יש לנו מקום בשבילך." | "אוהבת ילדים? יש לנו מקום בשבילך." |
| POV | "POV: [רגע מוכר מהחיים שלהם]" | "POV: סיימת שירות ואין לך מושג מה עכשיו" |
| Bold specific claim | "[מספר מפתיע] + [תוצאה]" | "7 דקות מהבית. זה כל הנסיעה שלך לעבודה." |
| Mid-action | Open inside the action, no intro | A hand stacking blocks → text "ככה מתחיל הבוקר שלנו" |
| Mid-conversation | Start mid-sentence | "…ואז היא אמרה לי: את חייבת לבוא לראות." |
| Contrast / pattern break | "לא עוד [הדבר הצפוי]." | "לא עוד עבודה שסופרים בה את הדקות." |
| Open loop / list | "3 דברים שאף אחד לא מספר לך על [X]" | "3 דברים שלא ידעת על עבודה במעון" |
| Challenge / quiz | "תבחרי: A או B?" | "בוקר עם קפה ושקט, או בוקר עם 12 חיבוקים?" |
| Testimonial first | Quote + face/name (with consent) | "\"באתי לשבוע ונשארתי שלוש שנים\" — שירה, מטפלת" |
| Local pride | Place name first | "הר ברכה, יש לנו הודעה בשבילך." |

## Rules
- Lead with the audience, not the brand. Logo can come at the end.
- One idea per hook. No greetings ("שלום לכולם"), no slow logo intro.
- Movement in frame 1 (a word slamming in, a zoom, a hand) — a static first frame loses.
- VO and text say the same thing; if the viewer is muted, the text alone must carry it.
- Don't bait-and-switch: the body must pay off the hook's promise.
