# Strategy toolkit

## Mining the insight (in the audience's words, not ours)

Sources, in order of value:
1. The user/client: "what do your best customers/employees say when they first call?"
2. Real comments, reviews, WhatsApp messages, Facebook group posts the user can paste in.
3. Objections: "why did people say no last time?"
4. Your own reasoning — label it `[השערה]` and ask the user to confirm.

Group the raw language into themes; each theme is a candidate angle:
**transformation · fear of missing out · social proof · problem → agitation → solution ·
product specificity · identity/belonging · behind the scenes · convenience**.

An insight is good when it is (a) true, (b) a little uncomfortable or surprising,
(c) phrased the way the audience talks. Test: would someone from the audience say "בדיוק!"?

Weak: "צעירות רוצות עבודה עם משמעות." Strong: "בסוף השירות הלאומי כולן שואלות 'ומה עכשיו?', ואף אחת לא רוצה לנסוע שעה לתל אביב בשביל זה."

## Funnel stage → message

| Audience temperature | They need | Hook style |
|---|---|---|
| Cold (never heard of us) | Name the pain / identity | Question, bold claim, POV |
| Warm (know us, not acted) | Proof, specifics, ease | Number, testimonial, demo |
| Hot (almost there) | Urgency, one-step CTA | Deadline, "שלחי 'אני' בוואטסאפ" |

## Frameworks to structure a script

- **PAS** — Problem → Agitate → Solution. Good for "don't care / don't know".
- **AIDA** — Attention → Interest → Desire → Action. General default.
- **BAB** — Before → After → Bridge. Great for transformation and visual contrast.
- **Hook → Proof ×3 → CTA** — performance/UGC style, easy to cut on beat.
- **Story (Pixar)** — "Every day… One day… Because of that… Until finally…". Emotional brand pieces.

## Format menu (pick different ones for the 3 concepts)

| Format | Why it works with young audiences | Needs |
|---|---|---|
| Kinetic typography on beat | Native to Reels, fully sound-off | Strong copy, music |
| POV / fake-UGC ("POV: סיימת שירות ו…") | Looks like content, not an ad | Phone-style framing, captions |
| Day-in-the-life (7:30 → 13:30) | Shows reality, builds trust | Real photos/clips or illustration |
| Chat/WhatsApp simulation | Instantly familiar, cheap to build | Good dialogue |
| List / countdown ("3 סיבות ש…") | Retention through open loop | 3 real reasons |
| Before → After | Clear value | A real contrast |
| Quiz / "תבחרי" | Interaction, comments | 2–3 choices |
| Testimonial quote cards | Proof for "don't believe" | Real quotes with consent |
| Map / place reveal | Local pride, "קרוב לבית" | Place name, map style |

## Concept scoring (1–5 each, show the table)

stops scroll · clear on mute · ownable · feasible with assets · on tone · CTA clarity.
Anything ≤2 on "clear on mute" or "feasible" is out.

## Testing plan

Same body, 3 hooks (change only the first 3 s). Metrics: 3-second view rate (hook rate;
<25% = weak hook), hold to 50%, CTR/messages. Change one variable per test.
