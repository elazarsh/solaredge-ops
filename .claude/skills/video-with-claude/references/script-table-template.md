# תבנית תסריט בטבלה (החוזה: מציגים למשתמש, מחכים ל"תפיק")

## כותרת
- **שם הסרטון:** …  **אורך משוער:** … דק' (~120 מילים/דקה)  **קהל:** …  **טון:** …  **סגנון:** … (בלוק סגנון נעול: …)
- **מסלול:** איור מונפש (תמונות+Veo+מעברים) | HTML (טיפוגרפיה/אינפוגרפיקה/הסבר) | משולב
- **קריין/ית:** Sulafat (עברית מנוקדת)  **מוזיקה:** …  **מה לא רוצים:** …
- **הערכת עלות:** N תמונות, N קליפי Veo, N קטעי מוזיקה, N פסקאות קול. **גיבוי אם מכסה נגמרת:** תמונה + תנועת מצלמה + מעבר.

## הטבלה
| # | נושא (משפט אחד) | הקראה (מנוקדת, כמו שנשמעת) | מה רואים | מה זז / מעבר לבא (ולמה) | צליל |
|---|---|---|---|---|---|
| 1 | | | | תנועה: … \| מעבר: dissolve/שריפה/… (סיבה נרטיבית) | מוזיקה m1, אפקט … |
| 2 | | | | | |

כללים לכל שורה:
- **הקראה:** ניקוד מלא (שמות: "נח" בלי ו'). בלי קיצורים. הטקסט על המסך רק מוסיף מה שהקול לא אומר.
- **מה רואים:** תיאור התמונה/הסצנה; טקסט עברי בתמונה נרשם במפורש (מילים מדויקות, יבדקו בקריאה חוזרת).
- **מה זז / מעבר:** תנועה פנימית (לא מצגת) + מעבר *משמעותי* לשורה הבאה. אותו אפקט לא יותר מ־3 פעמים.
- **סרטון הסבר:** סמן קטגוריה לכל קטע: **מושג כללי (כחול)**, **שיטת העבודה שלי (כתום)**, **דוגמה חיה (ירוק)**; לפחות 80% מהידע בקול.
- **cues (ל־HTML):** לכל סצנה רשימת [שם, מילת מפתח כפי שתתומלל, מופע n] לסנכרון.

## אישור
"כתוב **תפיק** כדי להתחיל, או כתוב הערות (איפה / מה / מה רוצים)."
