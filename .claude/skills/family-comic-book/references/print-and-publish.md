# פרסום: אתר ציבורי ו־PDF

## 1. אתר ציבורי
- `python tools/build_site.py "https://<user>.github.io/<public-repo>/"` בונה `site/`: `index.html` עם head מלא (charset, viewport, תיאור, og:image לשיתוף בוואטסאפ, favicon) ו־`art/*.webp` בלבד. כפתורי העריכה ומצב הבמאי מוסתרים.
- מעתיקים למאגר הציבורי ודוחפים. פעם אחת: Settings → Pages → Deploy from a branch → main → / (root). עדכון לוקח 1-3 דקות.
- לא מעלים `ref/`, `sources/`, `production/`, `handoffs/`.

## 2. PDF להדפסה
- `node tools/print_pdf.js he 300` פותח את האתר עם `?print`: פריסת הדפסה שבה **כל עמוד ממלא דף A4** (עמודים שהיו בנויים מחלקים צפים מקבלים עץ חיתוך מלא; האחרים מותאמים ליחס A4). מצלם כל דף כגיליון 300dpi (2480×3508).
- `python tools/print_pdf.py he` מחבר: `*-A4-print.pdf` (‏300dpi, ~35MB) ו־`*-A4-screen.pdf` (‏150dpi, ~10MB).
- סדר הדפים: כריכה קדמית, עמוד 1, עמוד המעבר לעבר, עמודי הסיפור, "המשך יבוא", כריכה אחורית. מספר עמודים שמתחלק ב־4 (חוברת).
- **כריכה קדמית:** איור מלא, שם הסדרה, כותרת גדולה, כותרת משנה, שורת פתיחה, "על פי סיפורו האמיתי של...", מסגרת זהב דקה.
- **כריכה אחורית:** תקציר שלא חושף את הסוף, "לכל המשפחה", QR לאתר (`pip install qrcode`).
- אין אזורים ריקים בשום דף: שוליים דקים כהים עם עותק רך של תמונת העמוד מתחת.
- הדפסה ביתית: "התאם לעמוד". בית דפוס: חוברת A4, כריכה בצד ימין (ספר בעברית).

## 3. גרסת צפייה פרטית
Artifact פרטי ב־claude.ai (או כל אחסון אחר) לעבודה שוטפת; האתר הציבורי רק למשפחה ולחברים.
