# קריינות סרטון התנור: טקסט מנוקד ובקשת הקול

## החתול (קול: Algenib, צרוד)
**הנחיית סגנון (להדביק לפני הטקסט):**
```
Speak Hebrew. A very old, world-weary street cat: a deep, rough, gravelly, hoarse baritone, the voice of a man who smoked for decades and spent endless hours on the street. Raspy chest voice, slow, dry, deadpan, very low energy, sardonic. A one-second pause after the first sentence with a small breathy exhale. Read ONLY the following text aloud, nothing else:
```
**טקסט:**
```
זֶה לֹא מִטְבָּח. זֶה תַּנּוּר לְיַד פַּח...
(הפסקה של שנייה)
...וְאֶת זֶה, הַמַּשָּׂאִית לֹא לוֹקַחַת.
```

## היונה: ההודעה בסוף (קול: Algieba, חלקלק ונלהב)
**הנחיית סגנון:**
```
Speak Hebrew. A warm, smooth, upbeat salesman baritone, fast and confident, a smile in the voice. Playful lift on "בְּקִצּוּר", clear emphasis on "לֹא נֶאֱסָף", slightly slower on the last phrase. Read ONLY the following text aloud, nothing else:
```
**טקסט:**
```
תּוֹשָׁבִים, בְּקִצּוּר: לְיַד הַפַּח – לֹא נֶאֱסָף. פְּסוֹלֶת גְּדוֹלָה, כְּמוֹ תַּנּוּר אוֹ סַפָּה? מְתַאֲמִים פִּנּוּי.
```

## היונה: הפתיחה (לצורך עקביות, אם מייצרים מחדש)
```
בֹּקֶר טוֹב! מִטְבָּח פָּתוּחַ! נוֹף לָרְחוֹב! תִּרְאוּ אֵיזֶה מִטְבָּח! כּוֹלֵל תַּנּוּר!
```

## הסלוגן
```
מִחוּץ לַפַּח? לֹא נֶאֱסָף!
```
