# סטודיו וידאו AI – מדריך עבודה

מדריך קצר לאיך מפיקים כאן סרטוני מושן־גרפיקס מקצועיים בעברית עם Claude, מה מותקן, ומה עוד חסר.

## 1. מה למדתי

### מהמדריך של אילון ([eilon.co](https://eilon.co/claude-motion-graphics-prompts/))
האתר חסום מהסביבה הזו, לכן למדתי ממנו דרך תוצאות חיפוש ומהמקורות שהוא נשען עליהם (Remotion ו-HyperFrames).
הרעיון המרכזי:
- Claude לא "מצייר" וידאו אלא **כותב קוד** (React ב-Remotion או HTML+GSAP ב-HyperFrames), ומרנדר אותו ל-MP4 בעזרת דפדפן headless ו-ffmpeg.
- כל פרומפט טוב בנוי מאותם שישה חלקים:
  1. **מה Claude שואל אותך** – המסר (3–6 מילים לכותרת), אורך (8–15 שניות לקליפ קצר), מידות (1080×1920 לרילס, 1080×1080 לפיד), פלטה של 3–4 צבעים חזקים.
  2. **איך זה נראה** – סגנון אחד מוגדר (למשל "כותרות ענקיות על רקע צבעוני שמתחלף בקאט על הביט").
  3. **מה קורה בכל שנייה** – טיימליין שנייה־אחר־שנייה.
  4. **איך לבנות** – טכניקה: spring/easing, stagger, מעברים.
  5. **טעויות שיש להימנע מהן**.
  6. **מה עושים לפני הקוד** – מאשרים בריף ופריים־בורד לפני שמתחילים לכתוב.

### מהסקילים הרשמיים (מותקנים ב-`.claude/skills`)
- **Remotion** (12 סקילים): `remotion-create`, `remotion-markup`, `remotion-captions`, `remotion-render` ועוד.
- **HyperFrames** של HeyGen (21 סקילים): `hyperframes` (נקודת כניסה), `motion-graphics`, `general-video`, `faceless-explainer`, `music-to-video`, `media-use` (קריינות/מוזיקה/כתוביות), `hyperframes-audio` (מיקס ו-ducking) ועוד.

## 2. מה הוספתי מעבר למדריך (לקחים לעברית ולסרטון גיוס)

| נושא | כלל |
|---|---|
| **RTL** | ב-HyperFrames **אסור** לשים `dir="rtl"` על `<html>`, כי זה מרנדר וידאו שחור. שמים `direction: rtl` על אלמנטי הטקסט בלבד. |
| **פונטים** | Google Fonts חסום בזמן רינדור, ולכן הפונטים מקומיים: Heebo, Rubik, Assistant, Secular One, Suez One, Karantina, Varela Round, Fredoka. לסרטון צעיר וחם: Rubik/Fredoka לכותרות ו-Heebo לגוף. |
| **הוק** | 1.5 השניות הראשונות קובעות. פותחים בשאלה או בתמונה רגשית ("אוהבת ילדים? 💛"), לא בלוגו. |
| **Safe zones ברילס** | להשאיר כ-250px למעלה וכ-350px למטה בלי טקסט חשוב, כי ממשק אינסטגרם/טיקטוק מכסה אותם. |
| **כתוביות** | כ-85% צופים בלי סאונד, ולכן כתוביות מלאות וגדולות, 2–4 מילים בכל פעם, מסונכרנות לקריינות. |
| **קצב** | 30–45 שניות לרילס גיוס. קאט כל 1.5–3 שניות. קריינות בקצב של כ-150 מילים לדקה. |
| **אודיו** | מוזיקה מתחת לקריינות בעוצמה של כ-18- עד 24- dB (ducking), ומאסטר סופי בסביבות 14- LUFS לרשתות. |
| **CTA** | הסיום נשאר על המסך לפחות 3 שניות: טלפון/וואטסאפ גדול ושם המעון. |
| **אמינות** | צילומים אמיתיים של המעון (בלי פנים של ילדים ללא אישור הורים!) עדיפים על תמונות AI גנריות. |
| **גרסאות** | לרנדר 9:16 (רילס/סטטוס) וגם 1:1 או 16:9 (פייסבוק/יוטיוב) מאותו קוד. |

## 3. מה מותקן ועובד (נבדק)

- `ffmpeg 6.1`, פונטים עבריים, `sox`
- **Remotion 4.0.530** ב-`video-studio/remotion`. קומפוזיציית בדיקה `HebrewSmokeTest` מרונדרת תקין.
- **HyperFrames CLI 0.8.96** + Chrome headless. תבנית עברית אנכית ב-`video-studio/hyperframes-starter` (GSAP מקומי כי ה-CDN חסום).
- 33 סקילים ב-`.claude/skills` (נשמרים בגיט ונטענים אוטומטית בסשנים הבאים).

**בסשן חדש** (הקונטיינר מתאפס) מריצים:
```bash
bash video-studio/setup.sh
```

## 4. מה חסר, ואיך משלימים ⚠️

הסביבה חוסמת את רוב שירותי ה-AI החיצוניים. מה שזמין ומה לא:

| יכולת | מצב | פתרון |
|---|---|---|
| **קריינות בעברית** | ❌ אין מנוע עברי מקומי. ElevenLabs, HeyGen ו-HuggingFace חסומים. | **מומלץ:** מפתח **Gemini API** (חינמי ב-aistudio.google.com). ה-API נגיש, Gemini TTS מדבר עברית טבעית, והסקיל `media-use` כבר תומך בו. חלופה: להקליט קריינות אמיתית (אמא/גננת מהמעון, הכי אמין!) ולהעלות MP3. |
| **מוזיקה** | ❌ ספריות מוזיקה חסומות | אותו מפתח Gemini (Lyria) יכול לייצר מוזיקת רקע. או להעלות קובץ MP3 ברישיון חופשי. |
| **תמלול לכתוביות** | ❌ מודלי Whisper חסומים | כתוביות מתוזמנות לפי הטקסט והקריינות, או תמלול דרך Gemini. |
| **תמונות/וידאו של המעון** | צריך ממך | להעלות לתיקייה `video-studio/assets/`. |

איך מוסיפים את מפתח Gemini: בהגדרות ה-Environment ב-claude.ai/code מוסיפים משתנה סביבה `GEMINI_API_KEY`. אם תרצה ElevenLabs, צריך גם להוסיף את `api.elevenlabs.io` לרשימת הדומיינים המותרים.

## 5. הבריף לסרטון "מטפלות למעון בהר ברכה" (טיוטה לאישור)

**מטרה:** גיוס מטפלות. **קהל:** נשים צעירות מהר ברכה והסביבה (בנות שירות, סטודנטיות, אמהות צעירות).
**טון:** צעיר, חם, אנרגטי, מקצועי. **פורמט:** 9:16, 30–40 שניות, קריינות נשית + כתוביות + מוזיקה אופטימית.

| שניות | סצנה | קריינות (טיוטה) |
|---|---|---|
| 0–2 | הוק: כותרת ענקית קופצת על רקע צבעוני | "אוהבת ילדים? יש לנו מקום בשבילך." |
| 2–8 | צילומי המעון / אייקונים מונפשים | "במעון ב[הר ברכה] אנחנו מגדלים את הדור הבא, עם הרבה אהבה וחיוך." |
| 8–18 | 3 יתרונות בקאטים על הביט | "צוות מגבש ותומך. שעות נוחות. הכשרה מקצועית ושכר הוגן." |
| 18–26 | רגע רגשי: נוף ההר, זריחה | "עבודה שיש בה משמעות, קרוב לבית." |
| 26–35 | CTA: טלפון/וואטסאפ גדול | "מחפשות מטפלות עכשיו. שלחי הודעה ובואי להכיר!" |

### שאלות שאני צריך ממך לפני שמתחילים
1. שם המעון, טלפון/וואטסאפ, ולוגו אם יש.
2. יתרונות אמיתיים: שעות, שכר, הכשרה, הסעות, ותק, גודל הקבוצות.
3. צבעי מותג או העדפת צבעים.
4. תמונות/סרטונים מהמעון (בלי פנים של ילדים), או שנלך על מושן־גרפיקס טהור.
5. קריינות: מפתח Gemini (אני מייצר) או הקלטה אמיתית שלך?
6. איפה יפורסם (אינסטגרם, פייסבוק, וואטסאפ סטטוס) כדי לקבוע גרסאות ומידות.

## 6. פקודות שימושיות

```bash
# Remotion
cd video-studio/remotion && npm run dev                          # Studio לתצוגה מקדימה
npx remotion render <CompositionId> out/video.mp4                # רינדור

# HyperFrames
cd video-studio/hyperframes-starter
npx hyperframes lint && npx hyperframes check                    # בדיקות
npx hyperframes render --quality draft -o out/draft.mp4          # טיוטה מהירה
npx hyperframes render --quality delivery -o out/final.mp4       # סופי
```
