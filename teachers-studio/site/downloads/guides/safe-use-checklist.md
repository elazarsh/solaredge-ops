# שימוש בטוח בכלי AI: רשימה למורה

המקור: הנחיות משרד החינוך (שאלות ותשובות על בינה מלאכותית, והנחיות לכלים בין־לאומיים). נבדקו ב־25.10.2026. המסמך הרשמי מחייב. זו רשימת תזכורת בלבד.

## לפני שמדביקים
- [ ] אין שמות, מספרי זהות, טלפונים או כתובות של תלמידים, הורים או צוות
- [ ] אין מידע רגיש או מוגן: אבחנות, מידע רפואי, נושאי רווחה
- [ ] אין קובץ שאסור לפרסם ברשת
- [ ] החומר שאני מעלה מותר לשכפול

## בחירת כלי
- [ ] נכנסתי לאתר האמיתי של הכלי (לבדוק כתובת), ולא לאתר מתחזה שגובה כסף
- [ ] בדקתי בקטלוג הכלים של משרד החינוך אם הכלי ברשימה
- [ ] אני יודע/ת שהאישורים של כלים משתנים, ובודק/ת מחדש מדי פעם

## מה מותר לתלמידים, לפי כיתה (עמוד הכלים הבין־לאומיים במרחב הפדגוגי)
| כיתות | מה מוגדר |
|---|---|
| א׳–ג׳ | אין אישור שימוש לתלמידים. שימוש לצוות ההוראה בלבד |
| ד׳ | התנסות רק דרך בוט משרד החינוך, ולא בכלים חיצוניים |
| ה׳–ז׳ | המורה מפעילה את הכלי, התלמידים משתתפים במליאה |
| ח׳ ומעלה | שימוש עצמאי בכלי בינה יוצרת מרשימת הכלים המאושרים |

## הנחיות נוספות מהמשרד
- מומלץ להירשם לכלים בכתובת דוא״ל נפרדת שאינה כוללת את שמכם.
- אין לאפשר לתלמידים לעבוד על מחשבים ברשת המנהלתית.
- מידע מוגן נשמר רק במערכות משרד החינוך ובשירותים מאושרים.

## אם נחשף מידע מוגן
1. לבטל מיד את הפעולה (הרשאה לענן, שליחת דוא״ל).
2. ליידע בהקדם את מנהל בית הספר.
3. המנהל מיידע את משרד החינוך: school_security@education.gov.il
4. מוקד בינה מלאכותית של המשרד: *6552, צוותי הוראה: 1 ואז 6.

## אחריות מקצועית
ה־AI יכול לטעות. אתם בודקים עובדות, מתאימים לכיתה, והחלטות על תלמידים נשארות בידי בני אדם.
