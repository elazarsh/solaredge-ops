# ערכת פרויקט למורה

ערכה של שבעה קבצים להקמת פרויקט קבוע ב־ChatGPT או ב־Claude. זו תבנית מקורית של ״הסטודיו של חדר המורים״ (חמ״ד בנים הר ברכה), לא משאב רשמי של אף חברה.

## מה בערכה

| קובץ | מה זה | לאן מעלים |
|---|---|---|
| `01-project-instructions.md` | הנחיות קבועות לפרויקט | מדביקים בשדה ההנחיות של הפרויקט |
| `02-class-profile.md` | מאפייני הכיתה, בלי פרטים מזהים | קובץ בפרויקט |
| `03-pedagogical-principles.md` | עקרונות פדגוגיים שלכם | קובץ בפרויקט |
| `04-design-rules.md` | כללי עיצוב והדפסה | קובץ בפרויקט |
| `05-quality-check.md` | בדיקת איכות | קובץ בפרויקט |
| `06-accumulated-knowledge.md` | ידע מקצועי מצטבר | קובץ בפרויקט, מעדכנים מדי פעם |

## איך מקימים (בקצרה)

**ב־Claude** (נבדק מול מרכז העזרה ב־25.10.2026):
1. בתפריט הצד: Projects, או הכתובת claude.ai/projects.
2. ״+ New Project״, שם ותיאור (Claude אינו רואה אותם).
3. ״Set project instructions״: הדביקו את `01`, ואז ״Save instructions״.
4. כפתור ״+״ בצד הימני של דף הפרויקט: העלו את קבצים 02 עד 07.
5. פתחו שיחה חדשה בתוך הפרויקט לכל משימה. שיחות בפרויקט אינן משתפות הקשר זו עם זו, אלא דרך ההנחיות והקבצים.

**ב־ChatGPT** (נבדק מול מרכז העזרה ב־25.10.2026):
1. צרו פרויקט חדש (דורש התחברות, זמין גם בחשבון חינמי).
2. שלוש הנקודות בפינת הפרויקט ← Project settings ← הדביקו את `01` כהנחיות.
3. העלו את קבצים 02 עד 07 לאזור הקבצים של הפרויקט. מספר הקבצים המותר תלוי בסוג החשבון.

## חשוב לדעת

- קובץ בשם מסוים אינו ״מופעל אוטומטית״ בכל מוצר. הפרויקט משתמש בקבצים כחומר רקע, ולכן ההנחיות מפנות אליהם בשמם.
- אל תכתבו בקבצים שמות או פרטים מזהים של תלמידים, ולא מידע רגיש.
- הקבצים הם טיוטות. התאימו אותם לכיתה ולשיטה שלכם.
- נכון ל־25.10.2026. תפריטים ושמות משתנים. אם משהו שונה, חפשו את המקביל.
