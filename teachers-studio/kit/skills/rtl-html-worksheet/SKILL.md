# דף עבודה או מסמך כ־HTML בעברית

## מתי להפעיל
כשהמורה מבקשת דף עבודה, כרזה, הזמנה, או כל מסמך מעוצב שיודפס או יוצג, ורוצה לשפר אותו בכמה סבבים.

## כללי הקובץ
- קובץ HTML יחיד ושלם, בלי קבצים חיצוניים ובלי ספריות.
- `<html lang="he" dir="rtl">` ו־`<meta charset="utf-8">`.
- צבעים, גופנים וגודל כתב כמשתני CSS ב־`:root`, כדי לאפשר שינוי ממוקד (ראו `print-template.html` שבתיקייה).
- כללי הדפסה: `@page` בגודל A4 עם שוליים, בלי שבירת עמוד באמצע שאלה או טבלה, ואפשרות לשחור־לבן.
- גופן מערכת קריא, כתב לא קטן מ־13 נקודות בהדפסה.
- ניגודיות גבוהה, ומידע לא מופיע רק בצבע.

## שלבי עבודה
1. סבב ראשון: מבנה ותוכן בלבד, בלי עיצוב מורכב.
2. סבב שני: עיצוב לפי כללי הצבע והגופן שהמורה הגדירה.
3. סבב שלישי: בדיקת הדפסה. ציון כמה עמודים נוצרו ואיפה נשברים.
4. כל בקשת שינוי של המורה מבוצעת כשינוי ממוקד, בלי לשכתב את כל הקובץ.

## מה לא לעשות
- לא להבטיח ייצוא ל־PDF, Word או תמונה בתוך הצ׳אט. ייצוא ל־PDF נעשה בהדפסה מהדפדפן אחרי בדיקה.
- אנימציית HTML אינה סרטון.
- לא לייצר טקסט עברי בתוך תמונה. הטקסט נכתב בקוד.
- לא להמציא לוגו או תמונות.
