# הסטודיו של חדר המורים

אתר עזר למורי בית הספר היסודי חמ״ד בנים הר ברכה: בוחרים צורך, עונים על כמה שאלות, ומקבלים הנחיה מקצועית מוכנה להעתקה לכלי AI. האתר אינו מפעיל מודל AI ואינו אוסף נתונים.

## מבנה

| נתיב | תוכן |
|---|---|
| `site/` | האתר הסטטי (HTML, CSS, JS). זו התיקייה שמפרסמים |
| `site/js/content/` | כל התוכן: שישה־עשר מסלולים, מנוע ההנחיות, הסיפור, הכלים, ההדרכה, תוכניות הלימודים |
| `site/js/views/` | המסכים |
| `site/downloads/` | קבצי ההורדה. נוצרים בבנייה, לא נערכים ידנית |
| `kit/` | מקור לתבניות מקוריות: ערכת הפרויקט, חמישה Skills, מדריכים וסקריפטים |
| `tools/` | בדיקות: קישורים, טעינת התוכן ל־Node |
| `build.mjs` | בונה את `site/downloads` ומוודא שכל קובץ שהאתר מפנה אליו קיים |

## הרצה מקומית

```bash
node teachers-studio/build.mjs           # יוצר את קבצי ההורדה
cd teachers-studio/site && python3 -m http.server 8765
# http://localhost:8765/
```

פתיחה ישירה של `index.html` כקובץ (`file://`) מציגה את האתר, אבל הורדות וצפייה בקבצים דורשות שרת.

## פרסום

האתר סטטי לגמרי ואין לו תלות בשרת, ולכן אפשר לפרסם אותו בכל אירוח סטטי.

- **GitHub Pages:** ה־workflow `.github/workflows/teachers-studio-pages.yml` מפעיל בנייה ופרסום. נדרש להפעיל פעם אחת Settings ← Pages ← Source: GitHub Actions.
- **Artifact ב־claude.ai:** `node build.mjs --artifact <תיקייה>` מכין חבילה שמתאימה לפרסום. יכולת ההורדה דורשת `capabilities: {downloads: true}`.

## החלפת הלוגו

הלוגו נמצא ב־`site/assets/logo.png` (הלוגו של בית הספר, חתוך לעיגול עם רקע שקוף מחוץ לו). להחלפה: מחליפים את הקובץ באותו שם.

## תוכן ובדיקות

- תאריך הבדיקה של כל הטענות על כלים: `TS.meta.checkedOn` ב־`site/js/content/catalog.js`.
- כל טענה על כלי מסומנת: ״אומת במקור״, ״דווח במקור משני״ או ״לא אומת״.
- `node tools/linkcheck.cjs` בודק שכל הקישורים מחזירים תשובה. אתרים שחוסמים בוטים (למשל chatgpt.com, claude.ai, github.com, help.openai.com, canva.com) מחזירים 403 גם כשהם תקינים.
- הסקר: נעשה שימוש בתמצית מצטברת בלבד (`site/js/content/training.js`). לא נשמרו שמות או תשובות גולמיות.
