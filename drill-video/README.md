## בנייה מחדש
```
python3 make_audio.py            # build/audio.wav
node render.js stills 30,80,100  # תצוגה מקדימה של פריימים → build/still_*.jpg
node render.js full out/x.mp4    # רינדור מלא
```
התמונות ב־`src/`, התזמון ב־`video.html` (הקבועים בראש הסקריפט: `SC`, `LIVE_SHOTS`, `HEADLINES`).
אותו ציר זמן מופיע גם ב־`make_audio.py`, ולכן שינוי תזמון בקובץ אחד דורש עדכון בשני.

## שימוש בקטעי וידאו משלך
הוסף קובץ ל־`src/` והחלף ב־`video.html` תג `<img>` של סצנת השידור החי בתג `<video muted>`, או ערוך
את הסרטון המוכן ב־CapCut / DaVinci והוסף את הקטעים שלך בין 0:53 ל־1:35.
