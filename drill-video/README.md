# סרטון פתיחה לתרגיל חירום ישובי – בית אל

`out/drill_exercise_beit_el.mp4` – 1:30 דקות, 1280×720, עם סאונד מסונתז (בלי קריינות).

## מבנה הסרטון
| זמן | סצנה |
|---|---|
| 0:00 | כרטיס פתיחה: "תרגיל חירום ישובי – כל האירועים דמיוניים" |
| 0:02 | שגרת בוקר בבית אל (05:42) ואז הפינה האמיתית: רחוב הרימון פינת רחוב החיטה |
| 0:14 | "צבע אדום" – אזעקות, בומים רחוקים, אזורים מוארים |

| 0:58 | מעבר "לפני / עכשיו" ושידור חי מהזירה – 6 זוויות |
| 1:24 | "זה הרגע. אירוע חירום בישוב. צוות החירום נכנס לפעולה." |

תג "תרגיל" מופיע לאורך כל הסרטון מרגע האזעקה.

## בנייה מחדש
```
python3 make_audio.py            # build/audio.wav
node render.js stills 30,80,100  # תצוגה מקדימה של פריימים → build/still_*.jpg
node render.js full out/x.mp4    # רינדור מלא
```
התמונות ב־`src/`, התזמון ב־`video.html` (הקבועים בראש הסקריפט: `SC`, `LIVE_SHOTS`, `HEADLINES`).
אותו ציר זמן מופיע גם ב־`make_audio.py`, ולכן שינוי תזמון בקובץ אחד דורש עדכון בשני.

## שימוש בקטעי וידאו משלך
הוסף קובץ ל־`src/` והחלף ב־`video.html` תג `<img>` של סצנת השידור החי בתג `<video muted>`, או ערוך
את הסרטון המוכן ב־CapCut / DaVinci והוסף את הקטעים שלך בין 0:34 ל־1:24.
