# SEO + GEO playbook

Standard SEO fundamentals also apply to AI features; there is no special AI file or "GEO schema", and no prompt guarantees ranking or citation. Everything below produces *drafts and evidence*; nothing is published without approval.

## Principles
- Business context once per session (name, site, profile URL, services, audience, real service areas, phone, verifiable strengths, three competitors, goals, available data, work already done). Read sources first, flag gaps.
- Use only supplied/observable sources; separate verified / hypothesis / missing; source + date on every metric; unobserved attribute = "unknown", not "no".
- No credentials in prompts; one step at a time; save each table.

## Local/profile steps (1-8)
1. **Categories:** search 3 service+area queries in maps (log date and conditions); table of primary/secondary categories for you and competitors.
2. **Attribute matrix:** you vs 3 competitors; group by how many competitors show each.
3. **Reviews:** up to 50 recent per business; sample size + window; recurring themes (praise/complaints); draft a neutral, incentive-free review request.
4. **Owner replies:** sample up to 30; 12 templates by star band with placeholders; no personal data.
5. **Post calendar (8 weeks):** check last 90 days; 3 posts/week; full drafts weeks 1-4, outlines 5-8, each with topic, CTA, photo description.
6. **Service descriptions:** compare site vs profile services; 2-3 sentences each; mind character limits.
7. **Business description:** three versions <= 750 chars (service-focused, choice-focused, trust-focused) with counts + recommendation.
8. **Photo plan:** compare types/variety; 8-week shoot plan with real locations and descriptive filenames; consent notes.

## Website steps (9-12)
9. **Keyword gap** (Semrush or similar export vs 3 competitors): start filters e.g. volume 100-2,000, difficulty < 40 as *starting points only*; choose <= 20 opportunities with a transparent scoring formula. No data -> qualitative only.
10. **Search Console pages:** 3 full months; commercial queries at avg position 4-15, CTR gaps, query-to-page mismatches; propose exact title/H1/intro/meta/link edits with priority, effort, success check.
11. **Service/area pages:** map existing pages first; add a new local page only with a real service and unique local evidence (title, meta, H1, slug, process, verified reasons to choose you, FAQs, CTA). Changing only the city name on identical content is not useful.
12. **30-day sprint:** queries at position 11-20 with >= 100 monthly impressions -> weekly tasks (titles/H1, content gaps, internal links, meta/messaging) + change log.

## GEO extension (13-15)
13. **Question mapping:** real customer questions (sales calls, search exports) for one service page -> direct answer first, then detail; cite sources; no invented stats; FAQ schema only if it matches visible content.
14. **Accessibility & accuracy check:** crawlability, status code, robots/noindex, canonicals, internal links, visible text, NAP consistency. Distinguish measurable from needs URL Inspection/server access.
15. **AI visibility sampling:** 10 non-branded purchase-intent questions, run manually in fresh chats without naming the business; log tool, date, mentions, links, cited sources, factual errors. Mention rate only from documented runs; retest under same conditions.

## Closing package
10-action summary, task sheet (source, status), implementation-ready drafts, content calendar, shoot plan, sprint, measurement plan.

## 6-week cadence and measurement
W1 context/categories/attributes -> W2 reviews/replies/posts -> W3 services/description/photos -> W4 keyword gap/GSC/question mapping -> W5-6 implement approved changes, check links, start AI sampling. Measure at 30/60/90 days: clicks, impressions, qualified leads, purchases, profile actions; log change dates; baseline missing != 0.
